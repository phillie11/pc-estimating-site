Questions between you and the site team, numbered per project (RFI-001).

- To ask a question, press **Raise RFI**, write it as the subject, and add a drawing reference or photo if it helps.
- When an RFI is with you, open it, write your answer and send it.
- **Waiting on me** shows the ones you need to answer.
