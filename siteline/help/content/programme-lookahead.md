The **look-ahead** shows what's planned in the next 2, 3 or 4 weeks, with a box for each working day, and anything that should already have finished marked **Behind**. Filter it by trade or subcontractor and print it for the site meeting. Subcontractors see only their own lines.

To bring in a programme from Microsoft Project or Asta Powerproject:

1. Save it as XML (Microsoft Project: File, Save As, "XML Format"; Asta: File, Save As, "Microsoft Project XML").
2. Choose **Import from MS Project** and upload the file. Nothing changes yet: you see what will be added and changed.
3. Press **Apply to the programme**.

Import an updated file the same way: lines are matched by their MS Project task ID, so they're updated, never duplicated. Lines you added by hand are left alone.
